# Dashboard Auditoria!

Meu Projetinho de dashboard para a auditoria interna, feito com Python, Flask, HTML, CSS, JavaScript, Bootstrap, Pandas, OpenPyXL, Plotly e Chart.js.

No login, coloque:

Usuário
12345

No terminal, rode:

```bash
python -m venv venv
```

Depois ative.

No Windows:

```bash
venv\Scripts\activate
```

No Linux:

```bash
source venv/bin/activate
```

Com o ambiente virtual ativado, rode:

```bash
pip install -r requirements.txt

```
Depois:

python app.py
```

Depois abra no navegador:

```text
http://127.0.0.1:5000
```
